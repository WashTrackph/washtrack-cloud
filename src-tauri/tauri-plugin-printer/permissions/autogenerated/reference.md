## Default Permission

Allows receipt printing via native print dialog

#### This default permission set includes the following:

- `allow-print-receipt`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`printer:allow-print-receipt`

</td>
<td>

</td>
</tr>

<tr>
<td>

</td>
